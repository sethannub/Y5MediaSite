# Image prompts

Images still to make for the site. Add the shared style line to the end of every
prompt so the set looks consistent. Save the result at the path given (WebP or
JPG), at the size given or larger, and the page picks it up once the
placeholder is swapped for the image.

**Shared style line**

> Editorial documentary photography, Dubai, natural light, real people mid-action, shallow depth of field, 35mm lens, subtle cool-green colour grade, no text, no logos, no watermarks, photorealistic.
